Hi there, I'm Ankita. Welcome to my personal slice of the internet. 

This repository holds the source code for my portfolio website — a place where I showcase the projects I've built, the little details I obsess over, and my journey as a developer.

## ✨ The Vision

I didn't want this to just be a standard list of projects. I wanted it to feel like an *editorial story*—something that combines structural discipline with a soft, magical aesthetic. 

The design heavily features:
- **Soft Glassmorphism:** Lots of frosted glass elements (`backdrop-blur`), subtle overlays, and glowing blooms that breathe life into the background.
- **Curated Typography:** I paired *Instrument Serif* and *Dancing Script* for a premium, magazine-like elegance, alongside *Plus Jakarta Sans* for clean readability.
- **Micro-interactions:** From twinkling sparkles to smoothly animating header pills and hover blooms, every interaction is deliberately crafted to feel satisfying without being overwhelming.

## 🛠 What's Under the Hood?

While the frontend is all about aesthetics, the architecture underneath is strictly engineered for performance and scalability.

- **React 19 & TypeScript:** The entire codebase is built with strict typing to ensure a bulletproof foundation.
- **Vite:** Used for instant HMR during development and heavily optimized, lightning-fast production builds.
- **Tailwind CSS:** All styling, including the custom gradients, bespoke animations (like the floating collage), and responsive behavior, is handled natively via Tailwind.
- **Data-Driven Architecture:** I decoupled the UI from the content. The entire site's data (my bio, experience, social links, and project showcases) lives in a single `portfolioConfig.ts` file. This means I can update my portfolio in seconds without ever touching the React components.

## 🚀 Live Integrations

To make the site feel alive, I've integrated a few dynamic features rather than just static text:
- **Live GitHub Contributions:** Fetching and displaying my real-time commit activity to reflect my actual, day-to-day coding trajectory.
- **Scroll-Aware Navigation:** The header and floating navigation dynamically adjust their styles and active states based on where the user is on the page.
